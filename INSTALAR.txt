  OPÇÃO 1 — INSTALAR VIA MICROSOFT EDGE (RECOMENDADO)
══════════════════════════════════════════════════

O Edge é o navegador que melhor suporta PWA no Windows
e permite instalar o app na barra de tarefas e menu iniciar.

IMPORTANTE: PWA só funciona via servidor HTTP, não direto
pelo arquivo. Use uma das opções abaixo:

─── USANDO LIVE SERVER (VS Code) ───────────────────
1. Instale o VS Code: https://code.visualstudio.com
2. Instale a extensão "Live Server" (Ritwick Dey)
3. Abra a pasta com os arquivos no VS Code
4. Clique em "Go Live" no rodapé
5. O Edge abrirá em http://127.0.0.1:5500/index.html
6. Clique nos 3 pontos (⋯) > Aplicativos > Instalar este site como aplicativo
7. Confirme e o app aparecerá no menu Iniciar e na área de trabalho!

─── USANDO http-server (Node.js) ────────────────────
1. Instale Node.js: https://nodejs.org
2. Abra o Prompt de Comando na pasta dos arquivos
3. Execute: npx http-server -p 8080 -c-1
4. Abra no Edge: http://localhost:8080
5. Clique nos 3 pontos (⋯) > Aplicativos > Instalar este site como aplicativo

─── USANDO PYTHON (já instalado?) ───────────────────
1. Abra o Prompt de Comando na pasta dos arquivos
2. Execute: python -m http.server 8080
3. Abra no Edge: http://localhost:8080
4. Instale conforme os passos acima

══════════════════════════════════════════════════
  OPÇÃO 2 — INSTALAR VIA GOOGLE CHROME
══════════════════════════════════════════════════

1. Siga os mesmos passos para subir o servidor local
2. Abra no Chrome: http://localhost:8080
3. Clique nos 3 pontos (⋮) > Salvar e compartilhar > Instalar página como app
4. Confirme o nome e clique em Instalar

══════════════════════════════════════════════════
  DICA — INICIAR AUTOMATICAMENTE COM O WINDOWS
══════════════════════════════════════════════════

Após instalar via Edge:
1. Clique com botão direito no ícone do app
2. Selecione "Fixar na barra de tarefas" para acesso rápido
3. Para iniciar com o Windows: Menu Iniciar > botão direito no app > Mais > Abrir local do arquivo
   Cole o atalho na pasta: %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup

══════════════════════════════════════════════════
  FUNCIONAMENTO OFFLINE
══════════════════════════════════════════════════

O app usa Service Worker para funcionar mesmo sem internet:
- Interface e gráficos ficam disponíveis offline
- Dados do Firebase requerem conexão para sincronizar
- Um aviso "⚡ Offline" aparece no canto superior quando sem internet
- Os dados são salvos localmente (IndexedDB) como backup automático
