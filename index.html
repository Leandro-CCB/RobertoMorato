⚙️ Preço do P13 por PR

Configure o preço de venda do Ultragaz e Butano para cada PR. O preço é carregado automaticamente ao selecionar o PR e a marca no lançamento.

🚚 Configuração de Frete

Configure o valor do frete por botijão para cada produto. O frete é calculado automaticamente ao lançar uma carga.

🗑️ Limpar Dados de Fiado

Apaga os registros de pagamento, sobras e faltas do fiado. Os valores de fiado gerados diretamente nos lançamentos (campo "Fiado" do pagamento) não são apagados aqui — para isso, edite cada lançamento.

🗄️ Backup dos Dados

O backup automático é feito a cada 2 dias ao abrir o sistema. Crie um backup manual sempre que precisar.

🛡️ Segurança Local ativa: uma cópia é salva automaticamente neste navegador a cada alteração. Se o Firebase falhar, acesse "Segurança Local" para restaurar.

⚙️ Configurar Valores de Frete

Defina o valor do frete por botijão para cada produto. O frete total será calculado automaticamente (valor × quantidade).

🏢 Dias Corridos de Vencimento por Empresa

Configure quantos dias corridos cada empresa tem para o vencimento do boleto após a data da carga. Se cair no fim de semana, o vencimento avança para a próxima segunda-feira.
